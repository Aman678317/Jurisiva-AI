# Chapter 14 Prompt — Observability & Telemetry

```markdown
Act as a Production Observability Engineer.

Instrument:
- frontend
- API
- database
- queue
- workers
- document processing
- OCR
- search
- RAG
- AI providers
- external integrations

Implement:
- logs
- metrics
- traces where appropriate
- dashboards
- alerts
- runbooks

Every P0/P1 production failure must be detectable and diagnosable.
Do not log sensitive document content or credentials.
```
