# Chapter 13 Prompt — Final QA Review & Release Sign-Off

```markdown
Act as the final Principal QA reviewer.

Read every previous validation report.
Inspect the repository.

Determine whether the implementation satisfies:
- PRD
- TRD
- security requirements
- AI requirements
- workflow requirements
- performance requirements
- quality requirements

Do not accept claims without evidence.

Return: PASS or FAIL

For every FAIL:
- requirement
- evidence
- risk
- fix
- test

Do not make assumptions in favor of release.
```
