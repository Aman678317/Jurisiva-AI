# Chapter 7 Prompt — Document Pipeline Testing Protocol

```markdown
Act as a Principal QA Engineer.

Build the complete document-processing test suite.

Test:
- formats
- OCR
- languages
- large files
- corruption
- security
- authorization
- tenant isolation
- retries
- idempotency
- worker crashes
- partial failure
- index rebuild
- deletion

For every failure create a regression test.
Do not accept flaky document-processing tests.
```
