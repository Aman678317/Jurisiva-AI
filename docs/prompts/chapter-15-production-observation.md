# Chapter 15 Prompt — Production Observation

```markdown
Act as a Principal SRE during production hypercare.

Analyze the current release.

Check:
- availability
- errors
- latency
- database
- queue
- workers
- OCR
- search
- AI
- external integrations
- security
- cost

Identify anomalies.
For every anomaly: severity, customer impact, probable cause, evidence, recommended action.
Do not modify production automatically.
```
