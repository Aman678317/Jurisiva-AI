# Chapter 12 Prompt — Backup & Restore Verification

```markdown
Act as a Site Reliability Engineer.

Perform a controlled disaster-recovery test.

Verify:
- database restore
- object restoration
- configuration recovery
- application startup
- data integrity
- tenant isolation
- audit integrity

Measure:
- RTO
- RPO
- actual recovery time
- missing dependencies

Do not claim disaster recovery capability until the test succeeds.
```
