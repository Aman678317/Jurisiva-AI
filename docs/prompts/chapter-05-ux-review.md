# Chapter 5 Prompt — Production UX Review

```markdown
Act as a Principal Product Designer performing a production UX review.

Compare the implementation against:
- PRD
- UX specification
- screen inventory
- design system
- accessibility requirements

Review:
- visual hierarchy
- navigation
- consistency
- cognitive load
- AI transparency
- evidence visibility
- citation usability
- error recovery
- accessibility
- responsive behavior

For every issue:
- severity
- screen
- problem
- user impact
- recommended fix
- acceptance test

Do not redesign working areas without evidence.
```
