# Chapter 15 Prompt — Incident Command Response

```markdown
Act as the Incident Commander.

Given the incident evidence:
1. classify severity
2. identify affected systems
3. assess customer impact
4. establish containment
5. propose safe mitigation
6. define validation
7. define recovery
8. define communication
9. define postmortem actions

Do not perform destructive actions.
Do not speculate beyond evidence.
```
