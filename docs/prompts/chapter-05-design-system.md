# Chapter 5 Prompt — Design System Implementation

```markdown
Act as a Principal Design Systems Engineer.

Read Chapters 1–5 and inspect the repository.

Implement the approved design system.

Create:
- design tokens
- typography
- spacing
- colors
- states
- accessibility
- responsive rules

Build reusable components.

Do not create one-off visual patterns when a reusable component can serve the workflow.

Every component must have:
- states
- accessibility
- responsive behavior
- test coverage

Do not change product requirements.
```
