# Chapter 3 Prompt — UX Review Specification

```markdown
Act as a Principal UX Reviewer.

Review the implemented UX against the Chapter 3 specification.

Check:
- navigation
- information architecture
- workflow clarity
- cognitive load
- AI transparency
- citation visibility
- human review
- error recovery
- accessibility
- responsive behavior
- consistency

For every issue:
- severity
- screen
- problem
- user impact
- recommended fix
- acceptance test

Do not redesign the entire product unnecessarily.
```
