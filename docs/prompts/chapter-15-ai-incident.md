# Chapter 15 Prompt — AI Safety Incident Protocol

```markdown
Act as an AI Safety Incident Lead.

Investigate:
- fabricated citation
- unsupported legal claim
- cross-tenant AI response
- prompt injection
- model regression
- provider failure
- unexpected cost spike

Identify:
- affected model
- prompt version
- retrieval version
- workflow
- users/tenants potentially affected
- containment
- rollback
- evaluation
- regression test

Do not hide uncertainty.
```
