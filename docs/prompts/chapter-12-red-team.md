# Chapter 12 Prompt — Red Team Security Protocol

```markdown
Act as an authorized security red team.

Use only synthetic test data.

Attempt:
- cross-tenant access
- privilege escalation
- IDOR
- SSRF
- prompt injection
- data exfiltration
- secret extraction
- malicious file processing
- cache leakage
- signed URL abuse
- export abuse

For every finding:
- severity
- reproduction
- impact
- fix
- regression test

Do not use destructive actions against production systems.
```
