# Chapter 11 Prompt — Source Research

```markdown
Act as a Principal Legal Research and Data Integration Engineer.

Read Chapters 1–11 and inspect the repository.

Design and implement controlled external research.

For every source determine:
- authority
- jurisdiction
- access method
- verification
- freshness
- terms/restrictions
- personal-data risk
- failure behavior

Never treat an arbitrary web result as authoritative.
Every retrieved fact must retain provenance.

If a source cannot be verified:
mark it unverified.
```
