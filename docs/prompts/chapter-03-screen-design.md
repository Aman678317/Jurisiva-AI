# Chapter 3 Prompt — Screen Design Specification

```markdown
Act as a senior enterprise UX/UI designer.

Read the PRD, information architecture, screen inventory and design-system requirements.

For each MVP screen produce:
- purpose
- layout
- components
- data
- actions
- permissions
- AI states
- loading
- empty
- error
- responsive behavior
- accessibility
- analytics

Use reusable components.

Do not create one-off UI patterns when an existing component can serve the workflow.

The UI must feel like a serious professional workspace, not a generic chatbot.
```
