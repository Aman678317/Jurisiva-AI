# Chapter 11 Prompt — Research Evaluation Harness

```markdown
Build a research evaluation dataset.

For every test question define:
- jurisdiction
- expected authoritative sources
- acceptable secondary sources
- irrelevant sources
- source conflicts
- expected citation
- expected abstention conditions

Measure:
- source quality
- citation correctness
- freshness
- conflict handling
- abstention
- latency

Block release on critical source-verification failures.
```
