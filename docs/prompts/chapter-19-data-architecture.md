# Chapter 19 Prompt — Data Architecture

```markdown
Act as a Principal Data Architect.

Inspect the current production architecture.

Design the minimum data platform required for: analytics, data lineage, entity resolution, property intelligence, matter intelligence, AI evaluation.
Do not introduce a warehouse or graph database unless justified by measured requirements.
Preserve tenant isolation and provenance.

Return: architecture, data flows, storage, cost, security, tradeoffs, migration plan, rollback plan.
```
