# Chapter 6 Prompt — Authorization & Security

```markdown
Act as an application security engineer.

Audit and implement authorization for the entire backend.

Build a permission matrix.

Verify:
- user
- organization
- matter
- resource

for every protected operation.

Test:
- cross-tenant access
- IDOR
- role escalation
- removed membership
- suspended user
- disabled user
- tampered IDs

Return every vulnerability with:
- severity
- endpoint/resource
- reproduction
- fix
- regression test

Do not rely on frontend authorization.
```
