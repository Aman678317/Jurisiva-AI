# Chapter 5 Prompt — Frontend Testing Protocol

```markdown
Act as a Principal Frontend QA Engineer.

Test the implementation against Chapters 3–5.

Test:
- navigation
- forms
- permissions
- loading
- empty
- errors
- AI states
- citations
- document viewer
- responsive behavior
- accessibility
- E2E workflows

Test both:
- happy path
- failure path

For every failure:
- severity
- screen
- reproduction
- root cause
- fix
- regression test

Do not accept flaky tests as passing.
```
