# Chapter 6 Prompt — Backend Implementation

```markdown
Act as a Staff Backend Engineer and Security Engineer.

Read Chapters 1–6 and inspect the repository.

Implement the approved backend architecture.

Priority order:
1. correctness
2. authorization
3. tenant isolation
4. data integrity
5. observability
6. testability
7. performance

Implement only approved functionality.

For every endpoint:
- authentication
- authorization
- validation
- business logic
- transaction safety
- audit
- structured errors
- tests

Never trust tenant/resource IDs supplied by clients.

After every implementation group:
- run tests
- inspect failures
- fix root causes
- add regression tests

Do not mark work complete while tests fail.
```
