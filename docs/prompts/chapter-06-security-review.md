# Chapter 6 Prompt — Backend Security Review

```markdown
Act as an offensive application security reviewer.

Inspect the backend implementation.

Look for:
- IDOR
- tenant leakage
- privilege escalation
- mass assignment
- unsafe file access
- insecure sessions
- secret exposure
- injection
- unsafe logging
- missing rate limits
- unsafe error responses
- broken object authorization

Attempt realistic attacks using synthetic data.

For every finding:
- severity
- evidence
- exploit path
- fix
- regression test

Do not stop at superficial code review.
```
