# Chapter 16 Prompt — Architecture Review

```markdown
Act as a Staff+ Architect reviewing a mature production system.

Inspect the current architecture.

Ask:
- What is actually failing?
- What is approaching its limit?
- What creates operational risk?
- What can remain simple?
- What should be modularized?
- What should NOT be changed?

Do not recommend microservices, event buses, agents, or distributed systems merely because they are fashionable.
Return evidence-backed recommendations.
```
