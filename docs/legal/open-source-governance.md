# Legal Operations & Open-Source Governance

## Open-Source License Policy
- Permitted open-source licenses: `MIT`, `Apache-2.0`, `BSD-3-Clause`, `ISC`.
- Prohibited copyleft licenses in core backend: `GPL-3.0`, `AGPL-3.0` (unless isolated via network boundary).
- Software Bill of Materials (SBOM) updated automatically on every build commit (`ci_pipeline`).
