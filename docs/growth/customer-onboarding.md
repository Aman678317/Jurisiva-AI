# Customer Onboarding & Cohort Activation Plan

## Onboarding Sequence & Time-to-First-Value
1. **Organization Creation & RBAC Setup**: Admin sets up advocate organization and invites team members (`LEAD_ADVOCATE`, `ASSOCIATE`).
2. **First Matter Workspace Setup**: Advocate creates first property title search matter.
3. **Document Ingestion & OCR Parsing**: Upload initial PDF title deeds; Indic OCR parses text with bounding-box page anchors within 60 seconds.
4. **First Evidence-Grounded Query**: Advocate asks copilot for encumbrance & extent checks; UI renders verified citations.
5. **Title Search Report Draft Generation**: Export initial draft report for advocate review.
