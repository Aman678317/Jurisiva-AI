# Customer & AI Feedback Classification Matrix

## Feedback Categorization & Actions

| Category | Description | Processing Action | SLA |
| :--- | :--- | :--- | :---: |
| **AI_CITATION_ERROR**| Incorrect page citation | Generates synthetic test case in `tests/regression/` | < 48 hrs |
| **OCR_PARSING_FAULT**| Misread survey number | Updates Indic OCR word dictionary fixture | < 72 hrs |
| **FEATURE_REQUEST** | Request for new state portal | Evaluates evidence and updates product roadmap | Quarterly |
| **UX_FRICTION** | UI layout or search filter issue| Queued for sprint UX refinement | Next Release |
