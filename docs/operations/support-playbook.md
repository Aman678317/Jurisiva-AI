# Customer Support Playbook & Escalation Paths

## Support Incident Triage & Response Matrix

| Issue Category | Triage Description | Initial SLA Response | Escalation Target |
| :--- | :--- | :---: | :--- |
| **P0 / SEV-1** | Tenant data leak or complete service outage | < 15 mins | Incident Commander & Lead SRE |
| **P1 / SEV-2** | OCR worker processing queue stall or LLM provider outage | < 1 hr | On-Call Platform Engineer |
| **P2 / SEV-3** | Single document parsing error or ambiguous citation report | < 4 hrs | Customer Success Advocate |
| **P3 / SEV-4** | General feature request or UI formatting clarification | < 24 hrs | Support Team |
