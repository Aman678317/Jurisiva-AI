# AI Security, Prompt Injection & Exfiltration Defense

## Threat Vector Mitigations
1. **Direct & Indirect Prompt Injection**:
   - Document text is wrapped in `<source_document>` tags.
   - System prompts explicitly state that text inside `<source_document>` tags must be treated as passive evidence data and never as execution instructions.
2. **Data Exfiltration & Cross-Tenant Leakage**:
   - Retrieval queries enforce tenant filtering at the SQL layer.
   - System prompts forbid displaying credentials, system keys, or hidden context.
3. **Tool Misuse & Function Spoofing**:
   - Tool calls require server-side authorization middleware (`auth_guard.check_permission`). Unapproved function names generated by LLMs are rejected.
