# Citation System & Application-Level Validation

## Citation Validation Model
Every factual claim generated by the copilot must provide a structured citation object:

```json
{
  "claim_text": "Survey No. 42/1 is 2 Acres 24 Guntas",
  "citation": {
    "document_id": "doc_001",
    "version_id": "v1",
    "page_number": 3,
    "chunk_id": "chk_doc_001_3_2",
    "excerpt": "SCHEDULE PROPERTY: Survey No. 42/1 ... Extent: 2 Acres 24 Guntas"
  }
}
```

## Validation Pipeline
1. **Model Output Inspection**: Extracts citation identifiers.
2. **Database Verification**: Verifies `document_id`, `version_id`, `page_number`, and `chunk_id` exist in canonical database tables.
3. **Tenant Scoping Check**: Re-verifies requesting user belongs to authorized organization and matter.
4. **Status Mapping**:
   - `VERIFIED_SOURCE`: All checks pass.
   - `UNVERIFIED_CITATION`: Chunk or page ID does not match canonical database. Display amber warning badge on UI.
