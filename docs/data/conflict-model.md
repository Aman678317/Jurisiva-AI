# Conflict Detection & Contradiction Model

## Contradiction Detection Rules
- When two documents or public sources present conflicting facts (e.g. Deed 1 Extent = 2A 24G vs Deed 2 Extent = 2A 10G), the system flags the relationship as `POSSIBLE_CONFLICT`.
- Both evidence paths are preserved with explicit citations. The system NEVER silences or merges conflicting facts automatically.
