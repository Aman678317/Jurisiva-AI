# Investor Due-Diligence Data Room & Cap Table Governance

## Data Room Index & Readiness Checklist
- **Corporate**: Articles of Incorporation, Board Resolutions, Shareholder Register.
- **Financial**: 24-Month Forecast, Bank Statements, Audited P&L Statements.
- **Product & Technology**: Architecture Specifications (Chapters 1-31), Security Test Suites (`SEC-001`, `SEC-002`).
- **Legal & IP**: Software Bill of Materials (SBOM), IP Assignment Agreements, Vendor DPA Contracts.
